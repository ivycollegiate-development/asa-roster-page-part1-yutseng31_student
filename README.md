# Roster Page, Part 1 — your own repo

This is **your** copy of the Roster Page starter for Coding/Design ASA. Only you and Mr. Jones can see it.

## What is in here

- `03-roster-table/index.html` — the starter page you edit today
- `03-roster-table/L03-Roster-Page-Part-1.md` — today's lesson, step by step

## First time on this machine

Set your git identity (once):

```
git config --global user.name "Your Name"
git config --global user.email "yourusername_student@ivycollegiate.org"
```

## Every class

Work in `03-roster-table/index.html`, then save and push:

```
git add .
git commit -m "add my row to the table"
git push
```

When git asks for a username, type your GitHub username. When it asks for a password, paste your **Personal Access Token** (not your GitHub password).

## Getting this repo into your workspace

```
cd ~
git clone https://github.com/ivycollegiate-development/asa-roster-page-part1-USERNAME.git
cd asa-roster-page-part1-USERNAME
```
